Searching with C++

Learn Linear Search and Binary Search step by step.

🔎 1. Linear Search

Linear Search me hum array ke elements ko one by one check karte hain.

Agar required element mil jaye, to uska index return kar dete hain.

Example:

Array = {10, 20, 30, 40, 50}
Target = 30

10 → ❌
20 → ❌
30 → ✅ Found

C++ Code:

#include <iostream>
using namespace std;

int main() {

    int arr[] = {10, 20, 30, 40, 50};
    int target = 30;

    for(int i = 0; i < 5; i++) {

        if(arr[i] == target) {
            cout << "Element found at index "
                 << i;
            return 0;
        }
    }

    cout << "Element not found";

    return 0;
}

Time Complexity:

O(n) — worst case me hume poora array check karna pad sakta hai.

⚡ 2. Binary Search

Binary Search sirf sorted array par apply hota hai.

Isme hum baar-baar array ko half me divide karte hain.

Example:

Array = {10, 20, 30, 40, 50}
Target = 40

Middle = 30
40 > 30

Right half me search karo:

40 → ✅ Found

Basic Logic:

start = 0
end = n - 1

while(start <= end)

    mid = (start + end) / 2

    if(arr[mid] == target)
        found

    else if(arr[mid] < target)
        start = mid + 1

    else
        end = mid - 1

C++ Code:

#include <iostream>
using namespace std;

int main() {

    int arr[] = {10, 20, 30, 40, 50};

    int target = 40;

    int start = 0;
    int end = 4;

    while(start <= end) {

        int mid = (start + end) / 2;

        if(arr[mid] == target) {
            cout << "Element found at index "
                 << mid;
            return 0;
        }

        else if(arr[mid] < target) {
            start = mid + 1;
        }

        else {
            end = mid - 1;
        }
    }

    cout << "Element not found";

    return 0;
}

Time Complexity:

O(log n)

📌 Linear Search vs Binary Search

Linear Search
Binary Search
Works on unsorted array
Requires sorted array
Checks elements one by one
Divides search space into half
O(n)
O(log n)
