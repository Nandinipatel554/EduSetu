Algebra

Learn the basics of algebra step by step.

What is Algebra?

Algebra is a branch of mathematics in which letters and symbols are used to represent unknown values.

Example:

x + 5 = 10

Here, x is the unknown value.

1. Variables & Constants

A variable represents a value that can change. A constant is a fixed value. 

Example:

3x + 7

x → Variable
3 → Coefficient
7 → Constant

2. Algebraic Expressions

An algebraic expression is a combination of variables, constants and mathematical operators. 

Examples:

2x + 5
3a - 7
x² + 2x + 1

3. Linear Equations

A linear equation has the highest power of the variable as 1. 

Example:

2x + 4 = 10

2x = 10 - 4

2x = 6

x = 3

4. Quadratic Equations

A quadratic equation is generally written in the form: 

ax² + bx + c = 0

Here, a ≠ 0.

Example:

x² + 5x + 6 = 0

5. Important Algebraic Formulas

(a + b)² = a² + 2ab + b²

(a - b)² = a² - 2ab + b²

(a + b)(a - b) = a² - b²

(a + b)³ = a³ + 3a²b + 3ab² + b³

(a - b)³ = a³ - 3a²b + 3ab² - b³

6. Example

Solve:

x + 8 = 15

x = 15 - 8

x = 7

Therefore, the value of x is 7.
