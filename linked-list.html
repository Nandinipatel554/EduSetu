Linked List with C++

Learn the basics of Linked List step by step.

🔗 What is a Linked List?

Linked List ek linear data structure hai jisme elements ko nodes ke form me store kiya jata hai.

Har node ke andar generally do parts hote hain:

  • Data — actual value store karta hai.
  • Next — next node ka address store karta hai.

Structure:

[10 | next] → [20 | next] → [30 | NULL]

🧩 1. Node

Linked List ka basic building block Node hota hai.

C++ Node:

class Node {

public:

    int data;
    Node* next;

    Node(int value) {

        data = value;
        next = NULL;
    }
};

Yahan data value store karta hai aur next next node ko point karta hai.

👑 2. Head

Linked List ke first node ko access karne ke liye hum head pointer use karte hain. 

Node* head = NULL;

Initially agar list empty hai to head NULL hota hai.

🏗️ 3. Creating Nodes

Hum dynamically nodes create kar sakte hain. 

Node* first = new Node(10);
Node* second = new Node(20);

first->next = second;

Structure:

[10 | next] → [20 | NULL]

🚶 4. Traversal

Traversal ka matlab Linked List ke har node ko one by one visit karna.

C++ Code:

Node* temp = head;

while(temp != NULL) {

    cout << temp->data << " ";

    temp = temp->next;
}
Example Output: 10 20 30

➕ 5. Insertion

Linked List me new node add karna insertion kehlata hai.

Insert at Beginning:

Node* newNode = new Node(5);

newNode->next = head;

head = newNode;

Before:

10 → 20 → 30

After inserting 5:

5 → 10 → 20 → 30

➖ 6. Deletion

Linked List se node remove karna deletion kehlata hai.

Beginning se first node delete karne ka basic idea: 

Node* temp = head;

head = head->next;

delete temp;

Isse old first node remove ho jata hai aur head next node par move ho jata hai.

📌 Array vs Linked List

Array
Linked List
Elements contiguous memory me store hote hain
Nodes different memory locations par ho sakte hain
Fixed size commonly used
Size dynamically grow/shrink ho sakta hai
Indexing directly possible
Sequential traversal required

⭐ Important Points

  • Linked List nodes se banti hai.
  • Har node me data aur next pointer hota hai.
  • Head first node ko point karta hai.
  • Last node ka next usually NULL hota hai.
  • Traversal me nodes ko one by one visit karte hain.
