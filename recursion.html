Recursion with C++

Learn recursion from the basics with simple examples.

🔁 What is Recursion?

Recursion ek technique hai jisme ek function khud ko hi call karta hai.

Har recursive function me generally do important parts hote hain:

  • Base Case — recursion ko stop karta hai.
  • Recursive Call — function ko dobara call karta hai.

Simple Example:

void printNumber(int n) {

    if(n == 0) {
        return;
    }

    cout << n << " ";

    printNumber(n - 1);
}

Agar printNumber(5) call karein: 

5 4 3 2 1

🛑 1. Base Case

Base case wo condition hoti hai jahan recursion stop ho jata hai. 

if(n == 0) {
    return;
}

Base case nahi hoga to function continuously call hota rahega.

🔄 2. Recursive Call

Recursive call me function khud ko dobara call karta hai. 

printNumber(n - 1);

Yahan har call me n ki value 1 se decrease ho rahi hai.

🧪 3. Dry Run

Function: 

void printNumber(int n) {

    if(n == 0) {
        return;
    }

    cout << n << " ";

    printNumber(n - 1);
}

Call: 

printNumber(3);

Step-by-step:

printNumber(3)
    ↓
print 3
    ↓
printNumber(2)
    ↓
print 2
    ↓
printNumber(1)
    ↓
print 1
    ↓
printNumber(0)
    ↓
return
Output: 3 2 1

✖️ 4. Factorial using Recursion

Factorial of n: 

n! = n × (n-1) × (n-2) ... × 1

Example: 

5! = 5 × 4 × 3 × 2 × 1
   = 120

C++ Code:

int factorial(int n) {

    if(n == 0 || n == 1) {
        return 1;
    }

    return n * factorial(n - 1);
}

Dry Run:

factorial(5)

5 × factorial(4)
      ↓
    4 × factorial(3)
          ↓
        3 × factorial(2)
              ↓
            2 × factorial(1)
                  ↓
                  1

Answer = 120

🌀 5. Fibonacci using Recursion

Fibonacci series me: 

0 1 1 2 3 5 8 ...

Har term previous two terms ka sum hota hai.

C++ Code:

int fib(int n) {

    if(n == 0 || n == 1) {
        return n;
    }

    return fib(n - 1) + fib(n - 2);
}

Example: 

fib(5)

= fib(4) + fib(3)
= 3 + 2
= 5

⭐ Important Points

  • Recursion me function khud ko call karta hai.
  • Base case recursion ko stop karta hai.
  • Recursive call problem ko smaller part me le jaata hai.
  • Har recursive function me stopping condition important hai.
