💻 C++ Quick Revision

Variables & Data Types

  • int → Integer values
  • float → Decimal values
  • char → Single character
  • string → Text
  • bool → true / false

Loops

  • for loop → Known number of repetitions
  • while loop → Condition-based repetition
  • do-while → Executes at least once

Arrays

  • Stores multiple values of same type.
  • Index starts from 0.
  • Example: arr[0], arr[1], arr[2]

OOP Basics

  • Class → Blueprint
  • Object → Instance of class
  • Inheritance → Reusing properties and methods
  • Polymorphism → One interface, different behaviour

🧮 Mathematics Quick Revision

Algebra

  • Variable → Quantity that can change
  • Constant → Fixed value
  • Expression → Combination of numbers and variables
3x + 6 = 18 → x = 4

Matrices

  • Matrix contains rows and columns.
  • Order = Number of rows × Number of columns.
2 × 3 Matrix → 2 Rows × 3 Columns

Differentiation

Basic power rule:

d/dx (xⁿ) = n xⁿ⁻¹

Probability

P(E) = Favourable Outcomes / Total Outcomes

🔬 Physics Quick Revision

Mechanics

F = ma
v = u + at

Work, Energy & Power

Kinetic Energy = ½mv²
Potential Energy = mgh
Power = Work / Time

Waves

v = fλ

Electromagnetism

V = IR

Modern Physics

E = mc²
