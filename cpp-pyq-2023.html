Question 1

What are the basic data types in C++? Explain any four with examples.

Some basic data types in C++ are:

int - stores integer values.
Example: int age = 20;

float - stores decimal values.
Example: float price = 10.5;

char - stores a single character.
Example: char grade = 'A';

bool - stores true or false.
Example: bool pass = true;

Question 2

Explain the difference between call by value and call by reference.

In call by value, a copy of the actual value is passed to the function, so changes inside the function do not affect the original variable.

In call by reference, the reference of the original variable is passed, so changes inside the function can affect the original variable.

Question 3

What is a class and object in C++?

A class is a blueprint or template used to create objects.

An object is an instance of a class.

Example:

class Student {
    public:
    int age;
};

Student s1;

Question 4

What is recursion in C++? Give a simple example.

Recursion is a process in which a function calls itself to solve a problem.

Example:

int factorial(int n) {
    if(n == 0)
        return 1;
    return n * factorial(n - 1);
}

Question 5

What is inheritance? Mention its common types in C++.

Inheritance is an OOP feature in which a derived class acquires properties and functions of a base class.

Common types include:

1. Single inheritance
2. Multiple inheritance
3. Multilevel inheritance
4. Hierarchical inheritance
5. Hybrid inheritance
