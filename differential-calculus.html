Differential Calculus

Learn limits and derivatives step by step.

What is Differential Calculus?

Differential calculus deals with the rate at which a quantity changes. The main concept used in differential calculus is the derivative.

Derivative → Rate of Change

1. Limits

A limit describes the value that a function approaches when the input approaches a particular value.

lim (x → 2) (x + 3) = 5

Here, when x approaches 2, the value of x + 3 approaches 5.

2. What is a Derivative?

The derivative tells us how quickly a function changes with respect to its input.

If y = x²

dy/dx = 2x

3. Basic Differentiation Rules

d/dx (c) = 0

d/dx (xⁿ) = nxⁿ⁻¹

d/dx (x) = 1

Here, c is a constant and n is a positive integer.

4. Derivatives of Common Functions

d/dx (sin x) = cos x

d/dx (cos x) = -sin x

d/dx (eˣ) = eˣ

d/dx (ln x) = 1/x

5. Product Rule

When two functions are multiplied, we use the Product Rule.

d/dx (uv) = u(dv/dx) + v(du/dx)

In simple words: first function × derivative of second + second function × derivative of first.

6. Quotient Rule

When one function is divided by another, we use the Quotient Rule.

d/dx (u/v) = [v(du/dx) - u(dv/dx)] / v²

7. Chain Rule

The Chain Rule is used when one function is inside another function.

d/dx f(g(x)) = f'(g(x)) × g'(x)

Example

Find the derivative of:

y = x³

Using the power rule:

dy/dx = 3x²
