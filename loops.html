C++ Loops

Learn how to repeat a block of code using loops.

📘 What are Loops?

A loop is used to execute the same block of code multiple times.

Instead of writing the same code again and again, we can use a loop.

🔄 For Loop

A for loop is commonly used when we know how many times we want to repeat something. 

for (int i = 1; i <= 5; i++) {
    cout << i << " ";
}

Output:

1 2 3 4 5

Here, i starts from 1 and increases by 1 after every iteration.

🔁 While Loop

A while loop runs as long as its condition is true. 

int i = 1;

while (i <= 5) {
    cout << i << " ";
    i++;
}

Output:

1 2 3 4 5

🔃 Do-While Loop

A do-while loop executes the code at least once before checking the condition. 

int i = 1;

do {
    cout << i << " ";
    i++;
} while (i <= 5);

Output:

1 2 3 4 5

🧠 Types of Loops

Loop Use
for When repetitions are known
while When condition controls repetition
do-while Runs at least once

💡 Understanding Increment

The ++ operator increases a variable by 1. 

int i = 1;

i++;

cout << i;

Output:

2
