🧮 Mathematics Formulas

Algebra

(a + b)² = a² + 2ab + b²
(a - b)² = a² - 2ab + b²
a² - b² = (a - b)(a + b)

Quadratic Equation

ax² + bx + c = 0
x = (-b ± √(b² - 4ac)) / 2a

Matrix

Order = Number of Rows × Number of Columns

Differentiation

d/dx (xⁿ) = nxⁿ⁻¹
d/dx (sin x) = cos x
d/dx (cos x) = -sin x

Integration

∫xⁿ dx = xⁿ⁺¹/(n+1) + C
∫1/x dx = ln|x| + C

Probability

P(E) = Favourable Outcomes / Total Outcomes

🔬 Physics Formulas

Motion

v = u + at
s = ut + ½at²
v² = u² + 2as

Force

F = ma

Work & Energy

Work = Force × Displacement
K.E. = ½mv²
P.E. = mgh

Power

Power = Work / Time

Waves

v = fλ

Electricity

V = IR
P = VI

Modern Physics

E = mc²

Optics

n = c / v
