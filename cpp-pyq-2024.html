Question 1

What is the difference between a while loop and a do-while loop in C++?

A while loop checks the condition before executing the loop body, whereas a do-while loop executes the body at least once and then checks the condition.

Question 2

Explain the concept of encapsulation in C++.

Encapsulation means wrapping data and functions together inside a class and controlling access to the data using access specifiers such as private, public and protected.

Question 3

What is an array? Write a simple example of a one-dimensional array.

An array is a collection of elements of the same data type stored under one name.

Example:

int marks[5] = {70, 80, 65, 90, 75};

Question 4

What is a pointer in C++?

A pointer is a variable that stores the memory address of another variable.

Example:

int x = 10;
int *ptr = &x;

Question 5

What is polymorphism in C++?

Polymorphism means "many forms". In C++, it allows the same function or interface to behave differently in different situations. Function overloading and function overriding are examples of polymorphism.
