Object Oriented Programming with C++

Learn the basic concepts of OOP step by step.

🏗️ What is OOP?

OOP stands for Object Oriented Programming. It is a programming approach based on objects and classes.

C++ supports OOP concepts such as classes, objects, encapsulation, inheritance and polymorphism.

📦 Class

A class is a blueprint or template used to create objects. 

class Student {
public:
    string name;
    int age;
};

Here, Student is a class.

🔹 Object

An object is an instance of a class. 

Student s1;

s1.name = "Rahul";
s1.age = 20;

Here, s1 is an object of the Student class.

🔐 Access Specifiers

Access specifiers control where class members can be accessed.

  • public → accessible from outside the class
  • private → accessible only inside the class
  • protected → mainly used with inheritance
class Student {
private:
    int marks;

public:
    string name;
};

🔧 Constructor

A constructor is a special function that is automatically called when an object is created. 

class Student {
public:

    Student() {
        cout << "Constructor called";
    }
};

int main() {

    Student s1;

    return 0;
}

The constructor has the same name as the class.

🔒 Encapsulation

Encapsulation means combining data and functions inside a class and controlling access to that data. 

class Student {

private:
    int marks;

public:

    void setMarks(int m) {
        marks = m;
    }

    int getMarks() {
        return marks;
    }
};

Here, marks is private and can be accessed using public functions.

🌳 Inheritance

Inheritance allows one class to acquire properties and functions of another class. 

class Animal {

public:
    void eat() {
        cout << "Eating";
    }
};

class Dog : public Animal {

public:
    void bark() {
        cout << "Barking";
    }
};

Here, Dog inherits from Animal.

🔄 Polymorphism

Polymorphism means many forms. The same function or operation can behave differently in different situations.

Two common types are:

  • Compile-time polymorphism
  • Run-time polymorphism
class Print {

public:

    void show(int x) {
        cout << x;
    }

    void show(string x) {
        cout << x;
    }
};

This is an example of function overloading.
