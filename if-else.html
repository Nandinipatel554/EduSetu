If / Else

Learn how to make decisions in C++ using conditions.

📘 What is If-Else?

In C++, if-else is used to make decisions based on a condition.

If the condition is true, the code inside if runs. Otherwise, the code inside else runs.

🔹 Basic If Statement

The if statement executes a block of code when the given condition is true. 

int age = 20;

if (age >= 18) {
    cout << "You are eligible.";
}

Output:

You are eligible.

🔀 If-Else Statement

We use else when we want to execute another block of code if the condition is false. 

int age = 16;

if (age >= 18) {
    cout << "Adult";
}
else {
    cout << "Minor";
}

Output:

Minor

🔎 Else-If

When we have multiple conditions, we can use else if. 

int marks = 75;

if (marks >= 90) {
    cout << "Grade A";
}
else if (marks >= 60) {
    cout << "Grade B";
}
else {
    cout << "Grade C";
}

Output:

Grade B

🧠 Conditions with Operators

Conditions can use relational operators such as:

Operator Meaning
== Equal to
!= Not equal to
> Greater than
< Less than
>= Greater than or equal to
<= Less than or equal to
