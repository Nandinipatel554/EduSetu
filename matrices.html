Matrices

Learn the basics of matrices step by step.

What is a Matrix?

A matrix is a rectangular arrangement of numbers or elements organized into rows and columns.

Example:

A = [ 1  2  3 ]
     [ 4  5  6 ]

This matrix has 2 rows and 3 columns. Therefore, its order is 2 × 3.

1. Rows and Columns

A row contains elements arranged horizontally, while a column contains elements arranged vertically.

A = [ 1  2 ]
     [ 3  4 ]

Here there are 2 rows and 2 columns.

2. Order of a Matrix

The order of a matrix is written as:

Number of Rows × Number of Columns

Example: A matrix with 3 rows and 4 columns has order 3 × 4.

3. Types of Matrices

Row Matrix: Has only one row.

[ 2  4  6 ]

Column Matrix: Has only one column.

[ 2 ]
[ 4 ]
[ 6 ]

Square Matrix: Number of rows equals number of columns.

[ 1  2 ]
[ 3  4 ]

4. Matrix Addition

Two matrices can be added when they have the same order. Corresponding elements are added.

[ 1  2 ] + [ 3  4 ]
[ 5  6 ]   [ 7  8 ]

Result:

[ 4  6 ]
[ 12  14 ]

5. Matrix Transpose

Transpose changes rows into columns and columns into rows.

A = [ 1  2  3 ]
     [ 4  5  6 ]

Transpose:

Aᵀ = [ 1  4 ]
     [ 2  5 ]
     [ 3  6 ]
