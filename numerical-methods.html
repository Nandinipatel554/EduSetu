Numerical Methods

Learn basic numerical techniques used to solve mathematical problems.

What are Numerical Methods?

Numerical methods are techniques used to find approximate solutions to mathematical problems when an exact solution is difficult or not convenient to calculate.

Mathematical Problem → Numerical Method → Approximate Solution

1. Errors in Numerical Computation

Numerical calculations may contain small differences between the exact value and the approximate value.

Error = Exact Value − Approximate Value

2. Bisection Method

The Bisection Method is used to find a root of an equation. The interval is repeatedly divided into two parts.

[a, b] → Divide into two halves → Select the required interval

This process is repeated until the required approximation is obtained.

3. Newton-Raphson Method

Newton-Raphson Method is an iterative method used to find the root of an equation.

xₙ₊₁ = xₙ − f(xₙ) / f'(xₙ)

We start with an initial approximation and repeatedly calculate a better approximation.

4. Secant Method

The Secant Method is another iterative technique for finding the root of an equation.

xₙ₊₁ = xₙ − f(xₙ)(xₙ − xₙ₋₁) / [f(xₙ) − f(xₙ₋₁)]

5. Numerical Integration

Numerical integration is used to approximate the value of a definite integral.

Common techniques include:

Trapezoidal Rule

Simpson's Rule

6. Trapezoidal Rule

The Trapezoidal Rule approximates the area under a curve using trapezoids.

∫ₐᵇ f(x) dx ≈ (b − a) / 2 × [f(a) + f(b)]

Example

Suppose we want to find an approximate root of an equation. We can choose an initial interval and repeatedly reduce it using a numerical method such as the Bisection Method.

Initial Interval → Smaller Interval → Approximate Root
