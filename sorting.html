Sorting with C++

Learn how to arrange elements in an array step by step.

🔄 What is Sorting?

Sorting means arranging elements in a particular order.

Usually hum numbers ko ascending order ya descending order me arrange karte hain.

Example:

Before Sorting:
{5, 2, 8, 1, 3}

After Sorting:
{1, 2, 3, 5, 8}

🫧 1. Bubble Sort

Bubble Sort me hum adjacent elements ko compare karte hain. Agar left element bada hai, to dono elements ko swap kar dete hain.

Example:

Array:
{5, 2, 4, 1}

First comparison:

5 > 2
Swap

{2, 5, 4, 1}

Then:

5 > 4
Swap

{2, 4, 5, 1}

Basic Logic:

for(int i = 0; i < n - 1; i++) {

    for(int j = 0; j < n - i - 1; j++) {

        if(arr[j] > arr[j + 1]) {

            swap(arr[j], arr[j + 1]);

        }
    }
}

C++ Code:

#include <iostream>
using namespace std;

int main() {

    int arr[] = {5, 2, 4, 1};
    int n = 4;

    for(int i = 0; i < n - 1; i++) {

        for(int j = 0; j < n - i - 1; j++) {

            if(arr[j] > arr[j + 1]) {

                swap(arr[j], arr[j + 1]);

            }
        }
    }

    for(int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }

    return 0;
}
Output: 1 2 4 5

Time Complexity:

O(n²)

🎯 2. Selection Sort

Selection Sort me hum har position ke liye minimum element find karte hain aur usse correct position par rakhte hain.

Example:

Array:
{5, 2, 4, 1}

Minimum = 1

1 ko first position par rakhenge:

{1, 2, 4, 5}

Basic Logic:

for(int i = 0; i < n - 1; i++) {

    int minIndex = i;

    for(int j = i + 1; j < n; j++) {

        if(arr[j] < arr[minIndex]) {
            minIndex = j;
        }
    }

    swap(arr[i], arr[minIndex]);
}

C++ Code:

#include <iostream>
using namespace std;

int main() {

    int arr[] = {5, 2, 4, 1};
    int n = 4;

    for(int i = 0; i < n - 1; i++) {

        int minIndex = i;

        for(int j = i + 1; j < n; j++) {

            if(arr[j] < arr[minIndex]) {
                minIndex = j;
            }
        }

        swap(arr[i], arr[minIndex]);
    }

    for(int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }

    return 0;
}
Output: 1 2 4 5

Time Complexity:

O(n²)

📌 Bubble Sort vs Selection Sort

Bubble Sort
