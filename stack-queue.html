Stack & Queue with C++

Learn Stack and Queue from the basics.

📚 1. What is a Stack?

Stack ek linear data structure hai jo LIFO principle follow karta hai.

LIFO = Last In, First Out

Example:

10
20
30  ← Top

30 sabse last me enter hua,
isliye sabse pehle bahar niklega.

➕ 2. Push Operation

Stack me new element add karna Push kehlata hai. 

Stack:

10
20
30  ← Top

Push(40)

10
20
30
40  ← Top

➖ 3. Pop Operation

Stack se top element remove karna Pop kehlata hai. 

Before Pop:

10
20
30  ← Top

Pop()

After Pop:

10
20  ← Top

💻 4. Stack in C++

C++ STL me stack available hai. 

#include <iostream>
#include <stack>
using namespace std;

int main() {

    stack<int> s;

    s.push(10);
    s.push(20);
    s.push(30);

    cout << s.top() << endl;

    s.pop();

    cout << s.top();

    return 0;
}
Output: 30
After pop: 20

🚶 5. What is a Queue?

Queue ek linear data structure hai jo FIFO principle follow karta hai.

FIFO = First In, First Out

Real-life Example:

People waiting in a line:

Person 1 → Person 2 → Person 3

Jo pehle line me aaya,
wo pehle bahar jayega.

➕ 6. Enqueue

Queue ke end me element add karna Enqueue kehlata hai. 

Queue:

10 → 20 → 30

Enqueue(40)

10 → 20 → 30 → 40

➖ 7. Dequeue

Queue ke front se element remove karna Dequeue kehlata hai. 

Before:

10 → 20 → 30

Dequeue()

After:

20 → 30

💻 8. Queue in C++

#include <iostream>
#include <queue>
using namespace std;

int main() {

    queue<int> q;

    q.push(10);
    q.push(20);
    q.push(30);

    cout << q.front() << endl;

    q.pop();

    cout << q.front();

    return 0;
}
Output: 10
After pop: 20

📌 Stack vs Queue

Stack
Queue
LIFO

Last In, First Out
First In, First Out
Insertion: Push
Insertion: Enqueue

⭐ Important Points

  • Stack follows LIFO.
  • Queue follows FIFO.
  • Stack me Push aur Pop operations important hain.
  • Queue me Enqueue aur Dequeue operations important hain.
  • C++ STL me stack aur queue available hain.
