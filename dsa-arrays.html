Arrays Basics

Learn the basics of arrays and solve simple problems.

📘 What is an Array?

An array is a data structure used to store multiple values of the same data type. 

int arr[5] = {10, 20, 30, 40, 50};

🔢 Array Indexing

Array indexing starts from 0. 

int arr[5] = {10, 20, 30, 40, 50};

cout << arr[0];
cout << arr[2];

Output:

10 30

So, for an array of size 5, the indexes are: 0, 1, 2, 3, 4.

🔄 Array Traversal

Traversal means visiting each element of the array one by one. 

int arr[5] = {10, 20, 30, 40, 50};

for (int i = 0; i < 5; i++) {
    cout << arr[i] << " ";
}

Output:

10 20 30 40 50

⌨️ Taking Array Input

We can take array elements from the user using a loop. 

int arr[5];

for (int i = 0; i < 5; i++) {
    cin >> arr[i];
}

for (int i = 0; i < 5; i++) {
    cout << arr[i] << " ";
}

⬆️ Find Maximum Element

We can use a loop to find the largest element in an array. 

int arr[5] = {10, 25, 7, 40, 15};

int maximum = arr[0];

for (int i = 1; i < 5; i++) {

    if (arr[i] > maximum) {
        maximum = arr[i];
    }
}

cout << maximum;

Output:

40

⬇️ Find Minimum Element

Similarly, we can find the smallest element. 

int arr[5] = {10, 25, 7, 40, 15};

int minimum = arr[0];

for (int i = 1; i < 5; i++) {

    if (arr[i] < minimum) {
        minimum = arr[i];
    }
}

cout << minimum;

Output:

7

🎯 Two Sum

In the Two Sum problem, we need to find two elements whose sum is equal to a given target. 

int arr[5] = {2, 7, 11, 15, 3};

int target = 9;

for (int i = 0; i < 5; i++) {

    for (int j = i + 1; j < 5; j++) {

        if (arr[i] + arr[j] == target) {

            cout << i << " " << j;
        }
    }
}

Output:

0 1

Because arr[0] + arr[1] = 2 + 7 = 9.

💡 Important Points

  • Array stores multiple values of the same type.
  • Indexing starts from 0.
  • Last index is size - 1.
  • Loops are commonly used to traverse arrays.
  • Two nested loops can be used for some basic array problems.
