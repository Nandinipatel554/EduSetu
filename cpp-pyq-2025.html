Question 1

What is a function in C++? Explain its basic syntax with an example.

A function is a block of code that performs a specific task. It can be called whenever that task is required.

Example:

int add(int a, int b) {
    return a + b;
}

Question 2

What is function overloading in C++?

Function overloading means having multiple functions with the same name but different parameters.

Example:

int add(int a, int b);
int add(int a, int b, int c);

Question 3

What is the difference between an array and a variable in C++?

A variable stores a single value, whereas an array stores multiple values of the same data type under one name.

Example:

int age = 20;
int marks[5];

Question 4

What is the purpose of a constructor in C++?

A constructor is a special member function of a class. It is automatically called when an object of the class is created.

Question 5

What is inheritance in C++?

Inheritance is an OOP concept in which one class can acquire the properties and functions of another class.
