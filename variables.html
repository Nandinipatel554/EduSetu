Variables & Data Types

Learn how C++ stores different types of data.

🔤 What is a Variable?

A variable is a named memory location used to store a value.

For example, if we want to store a student's age, we can create an integer variable.

💻 Example


#include <iostream>
using namespace std;

int main() {

    int age = 20;

    cout << age;

    return 0;
}

🖥️ Output

20
