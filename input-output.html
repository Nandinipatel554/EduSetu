Input / Output

Learn how to take input and display output in C++.

📘 What is Input / Output?

In C++, input means taking data from the user and output means displaying information on the screen.

⌨️ Taking Input using cin

We use cin to take input from the user. 

#include <iostream>
using namespace std;

int main() {

    int age;

    cin >> age;

    cout << age;

    return 0;
}

🖥️ Displaying Output using cout

We use cout to display information on the screen. 

#include <iostream>
using namespace std;

int main() {

    cout << "Hello EduSetu!";

    return 0;
}

Output:

Hello EduSetu!
