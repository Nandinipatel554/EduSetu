C++ Arrays

Learn how to store and work with multiple values.

📘 What is an Array?

An array is a collection of elements of the same data type stored together.

For example, instead of creating five separate variables for five numbers, we can store them in one array. 

int marks[5] = {80, 75, 90, 85, 70};

📝 Declaring an Array

We can declare an array by specifying its data type, name, and size. 

int numbers[5];

Here:

  • int → data type
  • numbers → array name
  • 5 → size of the array

📦 Array Initialization

We can give values to an array when creating it. 

int numbers[5] = {10, 20, 30, 40, 50};

🔢 Array Indexing

Array indexing starts from 0. 

int numbers[5] = {10, 20, 30, 40, 50};

cout << numbers[0];
cout << numbers[2];
cout << numbers[4];

Output:

10 30 50

So the indexes are:

Index Value
0 10
1 20
2 30
3 40
4 50

🔄 Traversing an Array

We can use a loop to access every element of an array. 

int numbers[5] = {10, 20, 30, 40, 50};

for (int i = 0; i < 5; i++) {
    cout << numbers[i] << " ";
}

Output:

10 20 30 40 50

⌨️ Taking Array Input

We can also take array elements from the user using cin. 

int numbers[5];

for (int i = 0; i < 5; i++) {
    cin >> numbers[i];
}

for (int i = 0; i < 5; i++) {
    cout << numbers[i] << " ";
}

💡 Important Points

  • Array stores multiple values of the same type.
  • Array indexing starts from 0.
  • The last index is size - 1.
  • Loops are commonly used to traverse arrays.
