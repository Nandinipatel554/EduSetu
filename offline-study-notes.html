C++ Short Notes

Quick revision notes for important C++ programming concepts.

1. C++ Introduction

C++ is a general-purpose programming language used for software development, problem solving and DSA.

#include <iostream>
using namespace std;

int main() {
  cout << "Hello World";
  return 0;
}

2. Variables & Data Types

A variable is a named memory location used to store data.

  • int → integer values
  • float → decimal values
  • char → single character
  • string → text
  • bool → true / false
int age = 18;
float marks = 85.5;
char grade = 'A';

3. Input & Output

cin is used for input and cout is used for output.

int age;
cin >> age;
cout << age;

4. Operators

  • Arithmetic → +, -, *, /, %
  • Relational → <, >, ==, !=
  • Logical → &&, ||, !
  • Assignment → =, +=, -=

5. If-Else

Used when a program needs to make a decision based on a condition.

if (age >= 18) {
  cout << "Adult";
} else {
  cout << "Minor";
}

6. Loops

Loops are used to repeat a block of code.

  • for loop → when repetitions are known
  • while loop → condition-based repetition
  • do-while → executes at least once
for(int i = 1; i <= 5; i++) {
  cout << i;
}

7. Functions

A function is a reusable block of code that performs a specific task.

int add(int a, int b) {
  return a + b;
}

8. Arrays

An array stores multiple values of the same data type. Indexing starts from 0.

int arr[5] = {10, 20, 30, 40, 50};

cout << arr[0]; // 10

9. Strings

A string is used to store a sequence of characters.

string name = "Sakshi";
cout << name;

10. OOP Basics

Object-Oriented Programming organizes programs using classes and objects.

  • Encapsulation
  • Inheritance
  • Polymorphism
  • Abstraction

11. Class & Object

A class is a blueprint, while an object is an instance of that class.

class Student {
public:
  string name;
};

Student s1;

12. Inheritance

Inheritance allows one class to acquire properties and functions of another class.

class Child : public Parent {
};

13. Polymorphism

Polymorphism means "many forms". The same function or operation can behave differently in different situations.

Mathematics Short Notes

Quick revision notes for important Mathematics concepts.

1. Algebra

Algebra deals with variables, constants and mathematical expressions.

  • Variable → A quantity whose value can change.
  • Constant → A fixed value.
  • Expression → Combination of numbers, variables and operators.
3x + 6 = 18

3x = 12
x = 4

2. Matrices

A matrix is an arrangement of numbers in rows and columns.

  • Row → Horizontal arrangement.
  • Column → Vertical arrangement.
  • Order → Number of rows × number of columns.
A = [ 1 2 ]
[ 3 4 ]

Order = 2 × 2

3. Determinants

A determinant is a scalar value associated with a square matrix.

| a b |
| c d |

Determinant = ad - bc

4. Differential Calculus

Differentiation measures the rate of change of a function.

d/dx (xⁿ) = n xⁿ⁻¹

Example:
d/dx (x²) = 2x

5. Integral Calculus

Integration is used to find accumulated quantities and is closely related to differentiation.

∫ xⁿ dx = xⁿ⁺¹ / (n+1) + C

6. Differential Equations

A differential equation contains a function and its derivatives.

dy/dx = 2x

Integrating:
y = x² + C

7. Probability

Probability measures the chance of an event occurring.

P(E) = Favourable Outcomes / Total Outcomes

8. Statistics

Statistics deals with collecting, organizing and interpreting data.

  • Mean → Average of values.
  • Median → Middle value after arranging data.
  • Mode → Most frequently occurring value.
Mean = Sum of observations / Number of observations

9. Numerical Methods

Numerical methods are techniques used to find approximate solutions to mathematical problems.

  • Bisection Method
  • Newton-Raphson Method
  • Numerical Integration

Physics Short Notes

Quick revision notes for important Physics concepts and formulas.

1. Mechanics

Mechanics deals with motion, force and the effect of forces on objects.

  • Velocity → Rate of change of displacement.
  • Acceleration → Rate of change of velocity.
  • Force → Push or pull acting on an object.
F = ma
v = u + at
s = ut + ½at²

2. Work, Energy & Power

Work is done when a force causes displacement. Energy is the capacity to do work.

Work = Force × Displacement

Kinetic Energy = ½mv²

Potential Energy = mgh

Power = Work / Time

3. Thermodynamics

Thermodynamics deals with heat, temperature, work and energy transfer.

  • System → Part of the universe being studied.
  • Heat → Energy transferred due to temperature difference.
  • Temperature → Measure of thermal state.
First Law of Thermodynamics:

ΔQ = ΔU + W

4. Waves & Oscillations

A wave transfers energy from one place to another. Oscillation is a repeated motion about a mean position.

v = fλ

v = Wave velocity
f = Frequency
λ = Wavelength

5. Electromagnetism

Electromagnetism studies the relationship between electric and magnetic fields.

  • Current → Flow of electric charge.
  • Voltage → Potential difference.
  • Resistance → Opposition to current.
V = IR

V = Voltage
I = Current
R = Resistance

6. Optics

Optics deals with the behaviour and properties of light.

  • Reflection
  • Refraction
  • Interference
  • Diffraction
Refractive Index:

n = c / v

7. Modern Physics

Modern Physics deals with phenomena that cannot be fully explained by classical physics.

  • Quantum Physics
  • Photoelectric Effect
  • Atomic Physics
  • Nuclear Physics
E = mc²

8. Units & Dimensions

Units are standard quantities used to measure physical quantities. Dimensions represent a physical quantity in terms of basic quantities.

  • Length → metre (m)
  • Mass → kilogram (kg)
  • Time → second (s)
  • Current → ampere (A)
