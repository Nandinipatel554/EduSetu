Trees with C++

Learn the basics of Trees in Data Structures step by step.

🌳 What is a Tree?

A Tree is a non-linear data structure in which data is arranged in a hierarchical structure.

Unlike an array or linked list, a tree can have multiple connections between its elements. 

        1
       / \
      2   3
     / \
    4   5

📌 What is a Node?

Each element of a tree is called a Node.

A node contains data and links to its child nodes. 

struct Node {
    int data;
    Node* left;
    Node* right;
};

🌱 Root Node

The topmost node of a tree is called the Root. 

        10  ← Root
       /  \
      20   30

👨‍👩‍👧 Parent and Child

A node directly connected below another node is called its Child.

The node above it is called the Parent. 

        10
       /  \
      20   30

10 → Parent
20, 30 → Children

🍃 Leaf Node

A node that does not have any child is called a Leaf Node. 

        10
       /  \
      20   30
          /
         40

20, 40 → Leaf Nodes

🌳 Binary Tree

A Binary Tree is a tree in which each node can have at most two children.

These children are called:

  • Left Child
  • Right Child
        10
       /  \
      20   30
     /
    40

🔄 Tree Traversal

Traversal means visiting all the nodes of a tree.

Important tree traversals are:

  • Preorder
  • Inorder
  • Postorder

1️⃣ Preorder Traversal

Order: Root → Left → Right 

        1
       / \
      2   3

Preorder = 1 2 3

2️⃣ Inorder Traversal

Order: Left → Root → Right 

        1
       / \
      2   3

Inorder = 2 1 3

3️⃣ Postorder Traversal

Order: Left → Right → Root 

        1
       / \
      2   3

Postorder = 2 3 1

⭐ Important Points

  • Tree is a non-linear data structure.
  • The topmost node is called Root.
  • A node can have a Parent and Children.
  • A node without children is called a Leaf Node.
  • Binary Tree can have at most two children.
  • Main traversals are Preorder, Inorder and Postorder.
