Integral Calculus

Learn the basics of integration step by step.

What is Integration?

Integration is a mathematical process used to find the accumulation of quantities. It is also commonly used to find the area under a curve.

Integration ↔ Reverse of Differentiation

1. Indefinite Integration

An indefinite integral does not have fixed upper and lower limits. It contains an arbitrary constant C.

∫ x² dx = x³/3 + C

2. Basic Integration Rule

For a power of x, we use the power rule:

∫ xⁿ dx = xⁿ⁺¹ / (n + 1) + C

This rule is used when n ≠ -1.

3. Standard Integrals

∫ 1 dx = x + C

∫ x dx = x²/2 + C

∫ eˣ dx = eˣ + C

∫ 1/x dx = ln|x| + C

4. Integration of Trigonometric Functions

∫ sin x dx = -cos x + C

∫ cos x dx = sin x + C

5. Definite Integration

A definite integral has fixed lower and upper limits. It gives a specific numerical value.

∫ₐᵇ f(x) dx

Here, a is the lower limit and b is the upper limit.

6. Integration by Substitution

Substitution is useful when an expression contains a function along with its derivative.

Let u = g(x)

Then du = g'(x) dx

Example

Find the integral:

∫ x³ dx

Using the power rule:

= x⁴/4 + C
