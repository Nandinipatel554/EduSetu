Strings with C++

Learn the basics of strings step by step.

🔤 What is a String?

String characters ka collection hota hai. Hum string ka use words ya sentences store karne ke liye karte hain.

Example:

string name = "Sakshi";

string city = "Indore";

C++ me string use karne ke liye: 

#include <string>

📝 1. String Declaration

String declare karne ke liye string keyword use karte hain. 

string name;

Value assign karna: 

string name = "Sakshi";

⌨️ 2. String Input & Output

Using cin:

string name;

cin >> name;

cout << name;

Note: cin space ke baad ka text read nahi karta.

Using getline:

string sentence;

getline(cin, sentence);

cout << sentence;

getline() poori line read kar sakta hai, including spaces.

🔢 3. String Indexing

String me bhi array ki tarah indexing 0 se start hoti hai. 

string name = "Sakshi";

Index:

S → 0
a → 1
k → 2
s → 3
h → 4
i → 5

Access a character:

cout << name[0];

Output:
S

📏 4. String Length

String ki length find karne ke liye length() function use kar sakte hain. 

string name = "Sakshi";

cout << name.length();

Output:
6

🔁 5. String Traversal

String ke har character ko loop ki help se access kar sakte hain. 

string name = "Sakshi";

for(int i = 0; i < name.length(); i++) {

    cout << name[i] << " ";

}
Output: S a k s h i
