C++ Functions

Learn how to create and use functions in C++.

📘 What is a Function?

A function is a block of code that performs a specific task.

Functions help us divide a large program into smaller, reusable parts.

🔹 Creating a Function

A simple function can be created like this: 

void greet() {
    cout << "Hello EduSetu!";
}

Here, greet() is the name of the function. The void means that the function does not return a value.

📞 Calling a Function

Creating a function is not enough. We need to call it to execute its code. 

#include <iostream>
using namespace std;

void greet() {
    cout << "Hello EduSetu!";
}

int main() {

    greet();

    return 0;
}

Output:

Hello EduSetu!

📥 Function Parameters

Parameters allow us to pass data to a function. 

void greet(string name) {
    cout << "Hello " << name;
}

int main() {

    greet("Sakshi");

    return 0;
}

Output:

Hello Sakshi

📤 Returning a Value

A function can return a value using the return statement. 

int add(int a, int b) {

    return a + b;
}

int main() {

    int result = add(10, 5);

    cout << result;

    return 0;
}

Output:

15

🧠 Important Parts of a Function

Part Meaning
Return Type Type of value returned by the function
Function Name Name used to call the function
Parameters Data passed to the function
Return Sends a value back
